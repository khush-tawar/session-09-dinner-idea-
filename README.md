# Spaghetti Carbonara - Recipe Website

A beautiful, fully responsive static website showcasing my favorite dinner recipe: Spaghetti Carbonara!

## Features

✨ **8 Comprehensive Sections:**
- Hero section with stunning visuals
- About section with dish information
- Ingredients list with measurements
- Step-by-step recipe instructions
- Photo gallery
- Nutritional information
- Pro cooking tips
- Contact form

🎨 **Modern Design:**
- Clean, professional layout
- Responsive design (mobile, tablet, desktop)
- Light/Dark mode toggle
- Smooth animations and transitions
- CSS Grid and Flexbox layouts

♿ **Accessibility:**
- Semantic HTML5 elements
- ARIA labels for screen readers
- Alt text for all images
- Focus states for keyboard navigation
- High contrast ratios

🛠️ **Technical Stack:**
- Pure HTML5 (no frameworks)
- CSS3 with CSS Variables
- Minimal JavaScript (theme toggle only)
- No build tools required

## How to View

Simply open `index.html` in any modern web browser, or serve it with any static file server:

```bash
# Using Python
python3 -m http.server 8080

# Using Node.js
npx http-server

# Using PHP
php -S localhost:8080
```

Then visit `http://localhost:8080` in your browser.

## Browser Compatibility

Works in all modern browsers:
- Chrome/Edge (latest)
- Firefox (latest)
- Safari (latest)
- Opera (latest)

## Theme Toggle

Click the moon/sun icon in the navigation bar to switch between light and dark modes. Your preference is saved in localStorage.
